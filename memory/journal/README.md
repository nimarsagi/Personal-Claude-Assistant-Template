One subfolder per project/domain (canonical names come from setup, recorded in MEMORY.md; new ones are created on first use). Each holds three folders plus one file: `sessions/` — dated entries (YYYY-MM-DD.md), the memory of the work itself; `lessons/` — LESSONS.md, the key rules distilled from that work (Rule/When/Why format); `skills/` — that domain's own skills, which become active in a given project only when symlinked into that project's `.claude/skills/` (see rules.md, "Managing skills"); and `parked-for-later.md` — non-urgent work spotted mid-task and deliberately deferred there. Where anything gets filed, and how much journal a session may read, are in rules.md.
